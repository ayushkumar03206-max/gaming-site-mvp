# QA audit: 2026-11-18

Scope: Pathforge, Neon Dodge, Chroma Shift and the site around them. No new games were added.
Checkpoint: git tag `checkpoint-pre-audit` (= live commit `fd851a5`). All fixes are on branch `audit-fixes`.
**Nothing has been deployed.**

## 1–2. Bugs found and root causes

| # | Sev | Bug | Root cause | Status |
|---|---|---|---|---|
| 1 | P1 | A broken or missing game file only showed an error after **15.6 s** (measured on live) | `player.js` relied only on a 15 s timeout. When the iframe received a 404 page, nothing noticed that the page had loaded but the game never sent `gl:ready` | Fixed: 4 s grace after iframe `load`, plus a 20 s hard timeout. Error state + Retry, never a fake success |
| 2 | P1 | **Fullscreen did nothing** on browsers without the element Fullscreen API (e.g. iPhone Safari); confirmed on live with the API removed | `requestFullscreen` was missing, so the click silently did nothing | Fixed: CSS fallback fullscreen with an "Exit fullscreen" button and Esc |
| 3 | P1 | Pathforge Forge mode on **touch screens**: you couldn't see which cells are valid for a block | Valid cells were highlighted only with `:hover`, which touch screens don't have | Fixed: valid cells are always outlined and invalid ones dimmed |
| 4 | P1 | Any runtime error **after** a game loaded replaced the whole game with the error screen | `gl:error` was handled the same before and after `gl:ready` | Fixed: after ready, a dismissible notice with Restart appears and the game keeps running |
| 5 | P2 | Neon Dodge: after pausing, or leaving the frame while holding a key, the orb kept drifting on resume | `keys` held stale `true` values because `keyup` never arrives while blurred | Fixed: input state cleared on pause and crash |
| 6 | P2 | Neon Dodge: a touch drag in progress when a run ended made the orb jump at the start of the next run | The `drag` anchor wasn't reset in `start()` | Fixed |
| 7 | P2 | Mobile menu: Escape didn't close it, and neither did tapping outside | Not implemented | Fixed |
| 8 | P2 | Header and parent-page keyboard focus: after Restart or Fullscreen, arrow keys scrolled the page instead of moving in the game | Focus stayed on the parent's buttons | Fixed: the game iframe is re-focused after Restart, Fullscreen and ready |
| 9 | P2 | Contact, Privacy, Terms and Licensing pages showed **hello@example.com** as if it were real | The placeholder was rendered as a mailto link | Fixed: shows "contact email not yet published", and the build prints a CONFIG WARNING. No address was invented |
| 10 | P2 | `site.json` `base_url` was `https://example.com`, so local builds had wrong canonical, OG and sitemap URLs (CI overrode it) | Placeholder value | Fixed: set to the real Pages URL; `check_site.py` now reads `base_path` from the config |
| 11 | P2 | `package.json` created by `npm init` declared `"license": "ISC"`, which would mislabel proprietary code as open source | npm default | Fixed: `"private": true`, `"license": "UNLICENSED"` |
| 12 | P3 | Game detail pages said "Original work · reviewed", which overstates a review that was an automated initial import | Template wording | Fixed: now shows "Rights record (approved)" and links to the record |
| 13 | P3 | Category filter chips had no `aria-pressed` until clicked | Missing initial attribute | Fixed |
| 14 | P3 | Neon Dodge: no level-up feedback; nothing announced to screen readers | Not implemented | Fixed: "LEVEL N" banner, polite live region for level-ups and crashes, reduced-motion screen shake |

## 8. Not performed
- **Real Android / iPhone devices: NOT TESTED.** No physical devices were used.
- Safari / WebKit and Firefox engines: NOT TESTED (only Chrome was used).
- Real Fullscreen API in headed Chrome: NOT TESTED. Headless Chrome only exercised the fallback path.
- Long-session performance and frame rate on low-end hardware: NOT TESTED. rAF throttling in a hidden pane was observed and is expected browser behaviour.
- Neon Dodge laser and obstacle collisions in the browser: covered by unit tests of the collision maths (`circleRect`/`circleCircle`) and by observed crashes during play; no browser test aims an obstacle precisely.
- Screen-reader walkthrough (NVDA/VoiceOver): NOT TESTED.
- Open Graph preview images are SVG, which many social networks don't render. NOT FIXED: needs PNG thumbnails.

## 9. Remaining blockers
**Code P0: none known.** All three games load, play to completion, save progress, and recover from load failures in the tested browsers.

Launch blockers that need the **owner** (deliberately not invented or certified by the assistant):
1. Real contact email: set `contact_email` in `data/site.json`.
2. Privacy Policy and Terms are templates. **No legal review has happened.**
3. Rights records in `data/assets.json` were approved by `initial-import` (created by the AI assistant that wrote the code). The owner should confirm ownership with
   `python scripts/rights_review.py approve rights-<slug> --by "<owner name>" --note "<what you checked>"`.
4. "Gridlight Arcade" is a placeholder brand name chosen during the MVP build. Confirm it or replace it, and check trademark availability yourself.

## 10. Manual Android / iPhone checklist
For each of: Android Chrome, iPhone Safari, and one tablet. Check portrait and landscape.

- [ ] Home loads; the ☰ menu opens and closes; search works
- [ ] Game page: Play → loading spinner → game appears (no error box)
- [ ] Fullscreen: the game fills the screen; Exit works; the page doesn't scroll behind it
- [ ] Rotate the phone during play: the game re-fits and nothing is cut off
- [ ] **Pathforge**: tap a green cell to move; Forge shows outlined cells; a block on a dimmed cell is refused; Undo; AI replies; win/lose screen; 2-player mode
- [ ] **Neon Dodge**: drag anywhere, with the orb following without your finger covering it; the page does not scroll while dragging; pause button; switch apps → game is paused on return; crash → best score kept after reload
- [ ] **Chroma Shift**: taps register once (no double-tap zoom); hint glow visible; win → Next level; run out of moves → Retry; close the tab, reopen → progress kept
- [ ] Share button opens the phone's share sheet
- [ ] Turn on the system "Reduce motion" setting → no screen shake in Neon Dodge
- [ ] Airplane mode, then press Play → an error with "Try again" appears within ~20 s
